The Creative Business Management System is a web application I developed to help small creative businesses organize and manage their day-to-day operations. The system provides a centralized location for managing important business information, including clients and projects.
I developed this project as part of my coursework to practice designing and building a complete information system. The project required me to consider both the needs of the user and the technical structure needed to support those needs.
Through this project, I gained experience with application planning, database design, front-end development, and connecting different components of a web application. It also gave me experience taking a project from the requirements and design stages into development.
This project helped strengthen my understanding of how HTML, CSS, Python, Flask, and databases can work together to create a functional web application.
